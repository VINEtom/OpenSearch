# OIS 单条件和多条件查询清单

清单依据当前搜索后端和字段目录。字段数量表示代码配置的范围。实际命中取决于模型识别、已同步的字段值和当前索引批次。

## 单条件查询

### 患者字段

患者 BERT 一次接受一个字段等值条件。出生日期使用 `YYYY-MM-DD`。编号保留前导零。直接搜姓名或放疗号也可以走普通关键词搜索。

共 69 个字段。

- 性别、姓名、放疗号、出生日期、拼音、拼音首字母、病历号、诊疗号、民族、国籍、证件类型、证件号码
- 医保、医保号、身高、患者类型、放疗类型、特殊情况、研究入组、主诊医生、主管医生、住院医生、物理师、婚育史
- 饮酒史、吸烟史、子女数、签名方式、门诊号、挂号号、就诊卡号、患者卡号1、患者卡号2、患者卡号3、患者卡号4、住院次数
- 医生组、患者来源、住院科室、入院时间、出院时间、病区、床号、住院号、转诊医院、转诊科室、预计入院、入院备注
- 家庭电话、联系电话、其他电话、办公电话、邮箱、传真、其他号码、户籍地址、居住地址、地址标签、工作单位、单位地址
- 职业、备注、登记时间、登记人、首诊医生、推荐医生、体重、体温、联系人

本地实测「主诊医生为颜艳」返回 784 位患者。性别可用中文条件，直接搜 `unknown` 也可走普通关键词。文档原有的「性别为 male」在本地实测返回 400。年龄范围、身高范围等不属于当前患者单条件入口。

### 单据字段

### 普通姓名关键词

直接输入姓名会搜索所有结果类型的可搜索字段。关联患者姓名命中的诊断、计划申请单和其他单据会出现在各自的分类中。其他字段里出现同一关键词时，也可能返回对应记录。可查看结果卡片上的命中字段。 [浏览器验收报告](search-query-test-report.md)

## 多条件检索

| 入口 | 当前支持的组合 | 示例 |
| --- | --- | --- |
| 搜索框 | 一种病的确诊记录、最近 N 个月、确诊状态。病种和日期须落在同一条诊断上，结果按患者返回。 | 最近10个月确诊鼻咽癌。实测 14 位患者。最近10个月确诊肺癌实测 8 位患者。 |
| 搜索框 | 单据类型加一个字段条件。单据类型限定检索范围，字段条件限定值。 | 计划申请单加总次数至少 20。 |
| 网页 | 搜索词或已识别的结构化条件，加当前患者范围和结果分类。 | 选中当前患者，搜索「屏气」，再点「定位申请单」。 |
| 搜索 API | 查询词加患者范围、数据来源、结果分类。API 参数包括 `scope`、`patientId`、`source`、`type`。 | 搜索「屏气」并限定 EMR、指定患者及定位申请单。 |

鼻咽癌和肺癌可使用配置的 ICD 编码集合。其他病种要求在该批索引里能唯一识别出病名。诊断模型当前识别的是最近 N 个月，N 为 1–99 的整数。

### 当前不支持的组合查询

| 不支持的组合 | 示例 |
| --- | --- |
| 同一类单据的两个业务字段同时筛选 | 找成像方式为 CT 且定位部位为头部的定位申请单。 |
| 同时筛选两个患者字段 | 找主诊医生为颜艳且住院科室为放疗科的患者。 |
| 确诊病种和时间再加处方次数 | 最近三个月确诊鼻咽癌、处方不少于 20 次。本地实测返回查询错误。 |
| 在一句话里组合患者字段和单据字段 | 找主诊医生为颜艳、且有总次数至少 20 次的计划申请单的患者。 |
| 任一条件满足或排除某个值 | 找成像方式为 CT 或 MR 的定位申请单。找排除 CT 的定位申请单。 |

**如果模型误解析后返回 0 条，不能据此判断没有符合原条件的数据。** 实测「找成像方式为 CT 且定位部位为头部的定位申请单」时，系统把「头部」错当成成像方式的值，实际执行了「成像方式等于头部」。这次的 0 条只对应实际执行的条件。可以查看页面的「识别出的筛选条件」，核对系统实际查了什么。
