真实集成覆盖：

- 编号、同名患者、标题、类型、编码及跨来源正文的完整结果集合，包含大写患者 UUID 与小写 UUID 等价。
- 患者范围、来源、类型计数，编号精确匹配优先，五类详情和 UUID 关联，连续查看不修改源数据。
- 新增、修改、软删除、作废、恢复、患者资料更正、诊断状态及关联变化。
- 同库外键拒绝跨患者引用；跨库坏引用和 PMS／EMR／RVS 读取失败均保留旧批次。
- 首次未同步、首次批写失败、重试发布；更新批写失败、发布响应丢失、本地清单写入失败。
- 别名已发布而后续元数据写入失败时，依据活动别名恢复成功状态；后续真正失败仍保留失败记录。
- 固定批次的 20／5 分页、新批次 20／6 分页、重复查询稳定、旧批次不可用以及完整重建。

搜索引擎超时、分片失败和不精确总数的拒绝逻辑使用单元测试验证；未在真实集群中制造分片故障。

## 浏览器实际操作

| 场景 | 实际结果 |
| --- | --- |
| 跨来源正文与关联 | “屏气”返回 R1、T1、O4 三条；打开计划定位备注，沿 T1 → R1 → D1 查看对应原记录并返回 |
| 编号与同名患者 | `000123` 返回 8 条；“林示例”患者分类有两人，放疗号 `000123` 与 `00123` 分别展示 |
| 患者范围与来源 | 明确选择 P2 后只查该患者；刷新仍恢复范围、关键词和类型；诊断类型切换 RVS 后自动回到可用类型 |
| 失效关联目标 | T2 的来源申请单 R3 可打开，显示已删除及重试、返回入口 |
| 第二页返回 | 25 条分页结果为 20／5，无重复；从第二页末条进入详情并刷新，返回后仍在第二页，滚动位置恢复约 1044 px |
| 查询期间同步 | 新增第 26 条并同步后，旧查询仍为 25 条；翻页保持旧批次，显式刷新后变为 26 条并回第一页 |
| 未同步修改正文 | O4 正文改为“训练记录已更新。”；详情显示新内容、变化提示及旧命中片段，新正文没有虚假高亮；返回仍是旧查询三条 |
| 上级改关联 | R1 的诊断改为 D2，但 T1 自身版本未变；T1 详情仍正确提示关联变化并展示 D2 |
| 首次没有成功索引 | 临时移除活动别名后显示尚未同步，保留输入，不显示零条；注入批写失败后同时显示失败原因和未同步状态 |
| 接口中断与重试 | 停止实际 API 后，搜索失败保留条件及旧结果；详情失败保留患者身份和返回入口；恢复 API 后重试成功 |
| 旧请求晚返回 | 临时代理把“屏气”响应延迟 1800 ms，期间改搜“鼻咽癌”；新响应先返回，旧响应晚约 1523 ms 发出，页面持续显示后一次查询的 7 条结果 |
| 无匹配 | 搜“完全不存在的示例检索词”，显示零条、未找到匹配记录及修改／清空入口，与查询失败区分 |

## 浏览器查询时间

页面从发起 `fetch` 到响应 JSON 读取完成计时，包含浏览器到本地接口的请求往返与后端处理；不包含输入后 300 ms 等待及页面绘制。以下是开发环境的单次观测，不是并发压测或性能承诺。

| 查询 | 样例规模 | 页面显示耗时 |
| --- | --- | --- |
| 屏气，3 条结果 | 16 条索引记录 | 24 ms |
| 分页唯一词，第 1 页 | 41 条索引记录，命中 25 条 | 25 ms |
| 分页唯一词，第 2 页 | 同一批次，返回 5 条 | 22 ms |
| 鼻咽癌，7 条结果 | 恢复后的 16 条基线，经过临时代理 | 25 ms |
| 无匹配 | 恢复后的 16 条基线，经过临时代理 | 19 ms |

本次证据覆盖独立原型的完整链路；真实 OIS 数据接入、C# 服务和 Portal 导航适配尚未在本次运行中验证。
