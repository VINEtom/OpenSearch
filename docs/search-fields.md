# 当前可搜索字段

同一个源字段可以独立保留原值，也可以合并到全文索引。是否另外支持字段筛选，取决于查询是否需要指定字段、比较数值或限定日期。

| 用途 | 处理方式 | 例子 |
| --- | --- | --- |
| 全文检索 | 对姓名、标题、正文等分词，支持单个汉字匹配。可将只用于搜内容的文本合并成正文。 | 搜「屏气」可命中扫描备注或固定备注。 |
| 精确匹配 | 按完整字段值匹配。编号保留前导零。 | 搜放疗号或诊断编码。 |
| 字段筛选 | 按指定字段匹配，或按日期、数值范围筛选。 | 「成像方式为 CT」「年龄大于二十岁」。 |
| 保留原值 | 在快照中保留各字段及其空值，供导出和核对。 | 独立保存扫描备注和固定备注，正文仍可合并检索。 |

每条诊断、申请单和单据都带有所属患者的姓名和放疗号，这两项在各类结果里都能搜到。

## 患者

姓名支持文字匹配，放疗号支持精确匹配。出生日期以日期类型索引，启用患者字段模型时可按指定日期筛选。

输入「年龄大于二十岁」时，系统按查询当天的周岁换算出生日期范围，筛出已满 21 周岁的患者。也支持「至少」「小于」「至多」，以及用「且」或「并且」连接已支持的患者条件，例如「年龄大于二十岁且性别为女」。页面展示实际应用的条件，结果标出实际周岁和对应命中值。缺少出生日期的患者不进入年龄筛选结果。

输入「性别为男」「性别是女」或「性别为 male」时，按性别筛选患者。男、女、其他、未知以及 male、female 都可以。结果只包含患者。

下列字段来自患者信息页。空值不进入索引。患者扩展字段在 `patientFields` 中以字段名和值成对保存，字段筛选同时匹配这两项，因此主诊医生和住院医生可以分别筛选。用于文字匹配的内容同时汇总到 `patientProfile`。主诊医生、主管医生、住院医生和物理师保存的是医生姓名；患者表里的用户编号不参与搜索。主管医生查不到用户时，使用患者表中保存的姓名。

| 字段 | 匹配 |
| --- | --- |
| 性别 | 通过「性别为男」这类条件筛选；也可精确匹配「男」或「女」 |
| 拼音、拼音首字母 | 精确、文字 |
| 民族、国籍 | 精确、文字 |
| 病历号、诊疗号、门诊号、住院号、挂号号、就诊卡号、患者卡号 1–4、医保号 | 精确 |
| 证件类型、证件号码 | 精确 |
| 医保 | 精确 |
| 身高、体重、体温、子女数、住院次数 | 精确 |
| 患者类型、放疗类型、签名方式 | 精确 |
| 特殊情况、研究入组 | 精确、文字 |
| 主诊医生、主管医生、住院医生、物理师、首诊医生、推荐医生 | 精确、文字 |
| 婚育史、饮酒史、吸烟史 | 精确、文字 |
| 医生组、患者来源、住院科室、病区、床号 | 精确、文字 |
| 入院时间、出院时间、预计入院、登记时间 | 精确 |
| 转诊医院、转诊科室、入院备注 | 精确、文字 |
| 家庭电话、联系电话、其他电话、办公电话、传真、其他号码 | 精确 |
| 邮箱 | 精确 |
| 户籍地址、居住地址、地址标签、工作单位、单位地址、职业、备注 | 精确、文字 |
| 登记人 | 精确、文字 |
| 联系人（姓名、关系、电话写在一起） | 精确、文字 |

照片和照片文件名不进入搜索。治疗点只保存科室编号、当前库没有名称，也不进入搜索。

## 诊断

| 字段 | 匹配 |
| --- | --- |
| 诊断名称 | 文字 |
| 诊断编码 | 精确 |
| 诊断说明、备注、方法、家族史、其他肿瘤史、补充诊断、主管医生姓名、主诊医生姓名 | 文字 |

输入「最近三个月确诊鼻咽癌、处方不少于 20 次」或「最近 10 个月确诊鼻咽癌」时，按确诊诊断、确诊日期和病种编码筛选患者。带分次数时，还要求直接关联该诊断的有效申请单达到分次数下限。

## 其他单据

各类单据都搜索标题、单据类型，以及下表中的正文。

| 单据 | 正文 |
| --- | --- |
| 定位申请单、复位申请单 | 固定说明、扫描说明、固定备注、扫描备注、既往史、勾画审核失败原因、扫描部位、治疗部位、定位中心、标记、技术、成像方式、MR 协议、勾画系统、计划系统 |
| 一站式申请单 | 说明、固定说明、部位、协议模板、扫描部位、扫描协议、摆位容差、治疗容差 |
| 检查预约单 | 预约类型、备注 |
| 治疗单 | 备注。标题使用关联申请单的名称 |
| 自定义单据 | 说明、正文 |

定位申请单还可以按成像方式和定位部位筛选。输入「成像方式为 CT」或「定位部位为头部」时，结果必须满足这些字段。同一句里再写备注时，字段条件仍然必须满足，备注用于排序和展示相关正文。

定位申请单的「定位部位」筛选使用扫描部位。治疗部位独立保留原值，含义与扫描部位不同。

| 定位申请单字段 | 当前用途 |
| --- | --- |
| 成像方式、扫描部位 | 全文检索和独立字段筛选。 |
| 治疗部位、定位中心、技术 | 参与合并正文检索。同步时在 `simulationSourceFields` 中分别保留原值，导出后可核对取值和编码，再评估是否加入精确筛选。 |
| 扫描备注、固定备注 | 参与合并正文检索。同步时在 `simulationSourceFields` 中分别保留原值，供快照核对。 |

`simulationSourceFields` 中的原值随快照导出。当前正文命中按合并正文展示，高亮说明使用「正文」作为标签。
