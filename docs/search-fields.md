# 当前可搜索字段

同一个源字段可以独立保留原值，也可以合并到全文索引。是否另外支持字段筛选，取决于查询是否需要指定字段、比较数值或限定日期。

| 用途 | 处理方式 | 例子 |
| --- | --- | --- |
| 全文检索 | 对姓名、标题、正文等分词，支持单个汉字匹配。可将只用于搜内容的文本合并成正文。 | 搜「屏气」可命中扫描备注或固定备注。 |
| 精确匹配 | 按完整字段值匹配。编号保留前导零。 | 搜放疗号或诊断编码。 |
| 字段筛选 | 按指定字段匹配，或按日期、数值范围筛选。 | 「成像方式为 CT 的定位申请单」「主诊医生为颜艳」。 |
| 保留原值 | 在快照中保留各字段及其空值，供导出和核对。 | 独立保存扫描备注和固定备注，正文仍可合并检索。 |

每条诊断、申请单和单据都带有所属患者的姓名和放疗号，这两项在各类结果里都能搜到。

## 患者

姓名支持文字匹配，放疗号支持精确匹配。出生日期以日期类型索引，启用患者字段模型时可按指定日期筛选。

年龄比较的结构化筛选暂未开放。

输入「性别为男」「性别是女」或「性别为 male」时，按性别筛选患者。男、女、其他、未知以及 male、female 都可以。结果只包含患者。

下列字段来自患者信息页。空值不进入索引。患者扩展字段在 `patientFields` 中以字段名和值成对保存，字段筛选同时匹配这两项，因此主诊医生和住院医生可以分别筛选。用于文字匹配的内容同时汇总到 `patientProfile`。主诊医生、主管医生、住院医生和物理师保存的是医生姓名；患者表里的用户编号不参与搜索。主管医生查不到用户时，使用患者表中保存的姓名。

| --- | --- |
| 性别 | 通过「性别为男」这类条件筛选；也可精确匹配「男」或「女」 |

| 证件类型、证件号码 | 精确 |

| 身高、体重、体温、子女数、住院次数 | 精确 |
| 患者类型、放疗类型、签名方式 | 精确 |
| 特殊情况、研究入组 | 精确、文字 |
| 主诊医生、主管医生、住院医生、物理师、首诊医生、推荐医生 | 精确、文字 |

## 诊断

| 字段 | 匹配 |
| --- | --- |
| 诊断名称 | 文字。启用支持标题提取的诊断 BERT 后，可用完整标题做精确筛选。 |
| 诊断编码 | 精确 |
| 临床描述、备注、方法、家族史、其他肿瘤史、补充诊断 | 文字 |
| 主管医生、主诊医生 | 精确、文字 |

启用本地诊断 BERT 后，可按确诊日期范围和索引中的诊断名称找患者。鼻咽癌和肺癌可按配置的 ICD 编码集合筛选。诊断索引还保留关联处方分次数。

各类单据都搜索标题、单据类型，以及下表中的拆分字段。

| --- | --- | --- |
| 定位申请单、复位申请单 | 固定说明、扫描说明、固定备注、扫描备注、既往史、勾画审核失败原因 | 扫描部位、治疗部位、定位中心、标记、技术、成像方式、MR 协议、MR 扫描其他协议、勾画系统、计划系统、摆位、手臂位置、是否增强、定位方式、定位类型、定位目的、治疗类型、治疗设备类型、是否门控、门控方式、门控设备、是否光学表面、复位验证、勾画审核状态、是否4DCT、CT千伏、CT毫安、CT层厚、扫描上界、扫描下界、是否制模、制模时间、制模确认时间、制模设备、扫描设备、定位技师、制模技师、签署医生、审核医生、是否饮水、饮水量、饮水时间、是否腹压、是否穿刺、是否缩野、是否计划QA、是否院外、铅块编号、激光打点、口服对比剂、上界器官、下界器官、固定部位、其他固定部位 |

| 检查预约单 | 备注 | 预约类型 |
| 治疗单 | 备注。标题使用关联申请单的名称 | — |
| 自定义单据 | 说明、正文 | — |

定位申请单的拆分字段按明确单条件查询，例如「成像方式为 CT 的定位申请单」或「扫描说明包含屏气的定位申请单」。页面展示筛选条件和实际命中值。

拆分字段「扫描部位」保留源值，按完整值精确命中。治疗部位独立保留原值。

| 定位申请单字段 | 当前用途 |
| --- | --- |
| 成像方式、扫描部位 | 独立字段筛选；拆分字段按完整值精确命中。 |
| 治疗部位、定位中心、技术 | 指定字段完整值筛选；`simulationSourceFields` 保留原值供快照核对。 |
| 扫描备注、固定备注 | 指定字段文字查询，命中标明字段名；`simulationSourceFields` 保留原值供快照核对。 |

枚举名称字段只按完整值精确命中；源值由多个名称拼在一起时，搜其中一个名称不会命中。`simulationSourceFields` 中的原值随快照导出。拆分字段里找不到匹配内容时（如演示数据或多词查询跨字段），文字命中仍按合并正文展示，标签使用「正文」。

配置 `SEARCH_DOCUMENT_BERT_MODEL_DIR` 并使用重新发布的索引后，九类单据均可按各自的字段目录筛选。例如「找总次数至少 3 的计划申请单」只查计划申请单。模型单据筛选需要一个明确字段。省略类型时按目录查询适用单据。写明类型时只查该类。

本地独立预览可通过 `OPENSEARCH_INDEX_ALIAS` 指定索引别名，使用单独的 `RUNTIME_DIR` 保存快照和同步状态。前端和后端需使用同一个 `API_PORT`。
