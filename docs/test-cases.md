# OIS 搜索原型测试用例

本文是可供后续实现执行的测试设计。尚未建立或导入下列样例，尚未运行原型、查询或同步测试；所有预期结果均不表示已经验证通过。

业务规则见[需求](requirements.md)，字段与关联见[数据模型](data-model.md)，页面行为见[交互流程](interaction-flows.md)。下表的“需求章节”用于验收映射。

## 执行约定

- 基线数据记为 S0；每个修改、删除、故障或扩展用例独立恢复 S0，避免前一用例影响后续预期。
- 查询测试时钟固定为 `2026-11-08`，日期采用 `Asia/Shanghai`；跨日用例只推进测试时钟。翻页和返回保留提交查询时的计算日期与成功索引批次。
- `P1`、`D1`、`R1`、`T1`、`O1` 等是样例符号，后续生成器为每个符号分配并固定映射到独立 UUID；所有外键使用该映射，不以姓名或编号关联。
- 首次完整同步成功的批次记为 B0。后续操作按“修改样例 → 暂停样例写入 → 本地运行同步脚本 → 检查同步状态 → 重新查询”执行。浏览器只提供同步说明和状态读取。
- 表中未列出的筛选条件均为“不限”，范围为全部患者。患者集合按 UUID 比较，显示顺序另按交互及设计约定检查。
