# OIS 全局搜索原型测试用例

本文定义固定样例、测试操作和预期结果。实际执行环境、自动化结果与浏览器证据分别记录在 [验证记录](validation.md)。

业务规则见[需求](requirements.md)，字段与关联见[数据模型](data-model.md)，页面行为见[交互流程](interaction-flows.md)。表中的“需求章节”记录验收映射。

## 执行约定

- 基线数据记为 S0；每个修改、删除、故障或分页用例独立恢复 S0，避免前一用例影响后续预期。
- `P1`、`D1`、`R1`、`T1`、`O1` 等是样例符号，生成器为每个符号固定映射独立 UUID；所有引用使用 UUID，不以姓名或编号关联。
- 所有记录默认 `revision = 1`，创建与更新时间为 `2026-11-01T00:00:00+08:00`，`deleted_at`、`voided_at` 为空。下表另有说明时以表中值为准；修改递增版本并更新修改时间。
- 首次完整同步成功的批次记为 B0。更新按“修改样例 → 暂停写入 → 本地运行同步脚本 → 检查状态 → 重新查询”执行；浏览器提供同步说明和状态读取。
- 未指定时，患者范围、来源和对象类型均为全部。返回集合按来源、类型及 UUID 比较，总数指记录数；排序另按设计检查。
- 每个文本字段使用下表的完整内容，不自动拼接其他对象的正文或额外关键词。这样可核对准确的命中集合。
