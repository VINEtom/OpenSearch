沿用本地正式快照、独立虚构索引及 BERT v4 主模型和后备模型。指定类型与省略类型的用例，都逐页按快照计算的预期核对记录 ID、命中字段、取值和高亮。

- **扫描说明**：输入「找扫描说明为其他要求1的定位申请单」时，BERT 曾只提取「1」。后续索引补全使用了定位申请单中存在的「要求1」，多返回两条。修复后保留「其他要求1」，指定定位申请单返回 0 条；省略类型时命中 1 条复位申请单。
- **固定说明**：当值中含有「定位申请单测试001」时，BERT 容易把值内提到的单据类型当成范围。修复后保留完整值，由原输入指定的类型决定查询范围。
- **补充医嘱**：初次回归发现重试时可能把后续的「的」并入取值。现在只有从原文和索引同时核实的完整值才能替换已识别的值。该用例在计划申请单内恢复命中 3 条。

关键词使用同一索引上关闭结构化模型的搜索 API 做对照，逐页检查总数、ID、命中字段、片段和高亮范围。其中一条有 12,089 条结果，超过全局分页的 10,000 条上限，按结果分类补齐核对。
