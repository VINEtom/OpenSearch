## ADDED Requirements

### Requirement: 从页面发起手动同步

全局搜索页 SHALL 提供「同步数据」操作，发起与命令行相同的一次完整同步。同步进行中不得重复发起。成功后保留当前搜索结果并提示刷新。失败时 SHALL 保留上一批完整数据并显示失败原因。

#### Scenario: 在页面同步成功

- **GIVEN** 页面已有一批搜索结果
- **WHEN** 用户点击「同步数据」并且同步成功
- **THEN** 状态条更新最近成功同步时间，当前结果保持原批次，并提示刷新后查看新数据

#### Scenario: 同步进行中或失败

- **WHEN** 同步尚未结束，或来源、引用、写入导致本次同步失败
- **THEN** 进行中不能再次点击；失败后继续使用上一批完整数据，并显示失败原因
