## ADDED Requirements

### Requirement: 按定位申请单字段查找

全局搜索 SHALL 支持按成像方式和定位部位查找定位申请单，并显示识别出的条件。选择两个条件时，同一张单据必须同时满足。

#### Scenario: 分别或组合查找

- **WHEN** 用户搜索「定位方式是 CT」「定位部位是头部」或组合输入两项条件
- **THEN** 结果页显示识别出的条件，并且只返回字段符合条件的定位申请单

#### Scenario: 旧批次缺少字段

- **WHEN** 用户在不含定位申请单筛选字段的批次搜索这些条件
- **THEN** 结果页显示识别出的条件，并提示重新同步
