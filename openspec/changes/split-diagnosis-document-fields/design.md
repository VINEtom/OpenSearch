## Context

患者结果已经用 `patientFields`（字段名+值成对）+ `patientProfile`（文字汇总）实现了字段级匹配和命中标注。诊断和单据仍是合并正文。

## Goals / Non-Goals

复用患者字段的机制拆分诊断和各类单据。不改变定位申请单已有的成像方式、扫描部位结构化筛选，不引入新的条件语法。

## Decisions

每条诊断、申请单和单据新增 `recordFields`（字段名、值成对保存，嵌套精确匹配），自由文本字段同时按序拼进 `bodyText` 参与文字匹配；枚举名称字段只存 `recordFields`，不进 `bodyText`。数组值（部位、分段）拆成多条同名字段值，任一值精确命中。文字命中展示具体字段名和该字段完整值；拆分字段里找不到时退回原正文片段。命中展示沿用现有 `matchedFields`。

## Risks / Trade-offs

现有索引没有 `recordFields`，同步前枚举字段既不精确命中也不再出现在正文命中里；完成同步后恢复。多词查询跨字段时仍按正文整体命中并退回通用标签。

## Migration Plan

1. 类型、投影与映射扩展；真实源按分类表输出字段和文字正文。
2. 查询接入 `recordFields` 精确匹配与命中标注。
3. 更新字段文档与测试，重新同步并验证。
