## Context

本 change 在独立的 OIS 原型仓库中规划全局搜索和临床条件筛选。完整设计见 [设计说明](../../../docs/design.md)，字段见 [数据模型](../../../docs/data-model.md)，页面见 [交互流程](../../../docs/interaction-flows.md)。

## Goals

使用实际的原型数据源验证跨来源搜索、具体诊断下的关联判断和可追溯详情。预期行为以本 change 的三份 delta specs 及 [需求说明](../../../docs/requirements.md) 为准。

## Decisions

- React/Umi 页面通过轻量本地只读接口访问搜索和业务详情；组成及接口见设计说明。
- 三个 PostgreSQL 数据库保存五类源记录；具体关联、字段及约束见数据模型。
- OpenSearch 记录与患者两种投影同批生成，患者中的诊断采用嵌套对象，保证同一诊断满足组合条件。
- 手动全量同步完成校验后一起切换查询索引；最新详情与查询时的依据分开展示。
- 年龄按筛选当天计算周岁；无关联计划按全部匹配诊断判断。精确条件语义和边界集中在需求说明。

## Risks / Trade-offs

跨来源读取时点、索引更新延迟、未知值和详情变化的处理见设计说明的“风险与处理”和“本地运行与回滚”。后续实现需要用 [测试用例](../../../docs/test-cases.md) 中的反例验证，文档完成不代表运行验证完成。
