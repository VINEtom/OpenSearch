## ADDED Requirements

### Requirement: 按定位申请单的全部拆分字段查询

全局搜索 SHALL 支持指定定位申请单的拆分字段查询，返回符合全部条件的定位申请单，并显示应用条件和实际命中的字段值。

#### Scenario: 指定字段和值
- **WHEN** 用户查询「技术为某值」或「扫描说明包含某词」
- **THEN** 仅在指定字段内匹配，值为空的记录不命中

#### Scenario: 组合字段条件
- **WHEN** 用户搜索「成像方式为 CT 且 CT层厚小于3」
- **THEN** 只返回成像方式为 CT 且层厚小于 3 的定位申请单
