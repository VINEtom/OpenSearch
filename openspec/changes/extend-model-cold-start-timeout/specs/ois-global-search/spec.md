## MODIFIED Requirements

### Requirement: 按定位字段和正文线索搜索

全局搜索 SHALL 支持同时输入定位字段和正文线索。显示识别的字段，结果必须满足这些字段条件。模型可用时，结果页展示用于重排的原文片段。

#### Scenario: 搜索 CT 定位申请单及摆位备注

- **WHEN** 用户搜索「找成像方式为 CT、备注里说要趴着摆位的定位申请单」
- **THEN** 页面显示成像方式 CT，并在同一页候选中优先展示与俯卧摆位相关的单据及其正文片段

#### Scenario: 模型冷启动

- **GIVEN** 模型进程尚未拉起，首次组合查询触发加载
- **WHEN** 加载耗时较长但不超过 30 秒
- **THEN** 该次搜索等待加载完成，仍返回核对与重排后的结果

#### Scenario: 模型不可用

- **WHEN** 模型未启动、繁忙、超时或加载失败
- **THEN** 搜索仍返回按现有规则或关键词匹配的结果
